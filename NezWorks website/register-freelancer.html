ข้อตกลงสำหรับคนรับงาน

เพื่อการทำงานที่ราบรื่นและเป็นธรรมสำหรับทั้งสองฝ่าย โปรดอ่านและยอมรับก่อนเริ่ม

01ค่าธรรมเนียม →
  • 0–20,000 บาท → 8%
  • 20,001–100,000 บาท → 7%
  • 100,001–300,000 บาท → 6%
  • 300,001 บาทขึ้นไป → 5%

ไม่มีค่าธรรมเนียมสมัคร/ลงบริการ — คิดเฉพาะงานที่สำเร็จ

02การชำระเงิน →

การชำระเงินดำเนินการผ่านระบบแพลตฟอร์ม โดยหักค่าธรรมเนียมตามอัตราก่อนโอนให้คนรับงาน เพื่อความปลอดภัยของทั้งสองฝ่าย

03การทำงานและการส่งมอบ →

ดำเนินงานตามรายละเอียด ราคา และระยะเวลาที่ตกลง หากมีการเปลี่ยนแปลง ให้ตกลงกันผ่านระบบ NezWorks เพื่อมีข้อมูลอ้างอิงชัดเจน

04การยกเลิกและข้อพิพาท →

หากไม่สามารถดำเนินงานต่อได้ แจ้งลูกค้าและ NezWorks เพื่อหาทางออกที่เหมาะสม หากเกิดข้อพิพาท NezWorks อาจขอหลักฐานจากทั้งสองฝ่ายเพื่อพิจารณาอย่างเป็นธรรม

05ผลงานและสิทธิ์ของผู้อื่น →

ส่งมอบเฉพาะผลงานที่ตนมีสิทธิ์ใช้งานหรือสร้างขึ้นเอง ไม่ละเมิดลิขสิทธิ์หรือสิทธิของบุคคลอื่น

06การรีวิว →

หลังจบงาน ทั้งสองฝ่ายให้คะแนนและรีวิวได้อย่างตรงไปตรงมา ไม่สร้างรีวิวปลอมหรือบิดเบือนคะแนน

07การใช้งานอย่างสุจริต →

ใช้แพลตฟอร์มอย่างสุจริต ไม่หลอกลวง ไม่ใช้ข้อมูลเท็จ ไม่หลีกเลี่ยงระบบหรือค่าธรรมเนียม หากพบพฤติกรรมเสี่ยง NezWorks อาจระงับการใช้งานชั่วคราว

08ข้อมูลส่วนบุคคล →

เก็บและใช้ข้อมูลเท่าที่จำเป็นต่อการให้บริการ ยืนยันตัวตน ชำระเงิน และความปลอดภัยของแพลตฟอร์ม ตามนโยบายความเป็นส่วนตัว
