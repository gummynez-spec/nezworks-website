เพื่อให้การทำงานบน NezWorks เป็นไปอย่างราบรื่นและเป็นธรรมสำหรับทั้งคนรับงานและลูกค้า เราขอให้คนรับงานรับทราบข้อตกลงพื้นฐานดังต่อไปนี้

01ค่าธรรมเนียม →

NezWorks มีค่าธรรมเนียมจากงานที่สำเร็จ โดยคิดตามระดับยอดขายสะสมของคนรับงาน

  • 0–20,000 บาท → 8%
  • 20,001–100,000 บาท → 7%
  • 100,001–300,000 บาท → 6%
  • 300,001 บาทขึ้นไป → 5%

ไม่มีค่าธรรมเนียมสำหรับการสมัครหรือการลงบริการ เว้นแต่มีการแจ้งเงื่อนไขเพิ่มเติมอย่างชัดเจน

02การชำระเงิน →

เพื่อความปลอดภัยของทั้งสองฝ่าย การชำระเงินสำหรับงานที่เกิดขึ้นผ่าน NezWorks จะดำเนินการผ่านระบบของแพลตฟอร์ม โดย NezWorks จะหักค่าธรรมเนียมตามอัตราที่กำหนดก่อนโอนเงินให้คนรับงาน

03การทำงานและการส่งมอบ →

คนรับงานควรดำเนินงานตามรายละเอียด ราคา และระยะเวลาที่ตกลงกับลูกค้า หากมีการเปลี่ยนแปลงรายละเอียดงาน ควรพูดคุยและตกลงกันผ่านระบบ NezWorks เพื่อให้มีข้อมูลอ้างอิงที่ชัดเจน

04การยกเลิกและปัญหาจากงาน →

หากเกิดเหตุที่ทำให้ไม่สามารถดำเนินงานต่อได้ สามารถพูดคุยกับลูกค้าและแจ้ง NezWorks เพื่อหาทางออกที่เหมาะสม

หากเกิดข้อพิพาท NezWorks อาจขอข้อมูลหรือหลักฐานจากทั้งสองฝ่ายเพื่อช่วยพิจารณาอย่างเป็นธรรม

05ผลงานและสิทธิ์ของผู้อื่น →

คนรับงานควรส่งมอบผลงานที่ตนเองมีสิทธิ์ใช้งานหรือสร้างขึ้นเอง และไม่ละเมิดลิขสิทธิ์หรือสิทธิของบุคคลอื่น

06การรีวิว →

หลังจบงาน ลูกค้าและคนรับงานสามารถให้คะแนนหรือรีวิวประสบการณ์การทำงานได้อย่างตรงไปตรงมา โดยไม่ควรสร้างรีวิวปลอมหรือพยายามบิดเบือนคะแนน

07การใช้งานอย่างสุจริต →

NezWorks ขอให้ผู้ใช้งานใช้แพลตฟอร์มเพื่อการทำงานอย่างสุจริต ไม่หลอกลวง ไม่ใช้ข้อมูลเท็จ และไม่พยายามหลีกเลี่ยงระบบหรือค่าธรรมเนียมของแพลตฟอร์ม

ในกรณีที่พบพฤติกรรมที่อาจส่งผลต่อความปลอดภัยหรือความน่าเชื่อถือของระบบ NezWorks อาจติดต่อเพื่อขอข้อมูลเพิ่มเติม หรือระงับการใช้งานเป็นการชั่วคราวตามความเหมาะสม

08ข้อมูลส่วนบุคคล →

NezWorks จะเก็บและใช้ข้อมูลส่วนบุคคลเท่าที่จำเป็นต่อการให้บริการ การยืนยันตัวตน การชำระเงิน และการดูแลความปลอดภัยของแพลตฟอร์ม โดยเป็นไปตามนโยบายความเป็นส่วนตัวของ NezWorks

การสมัครเป็นคนรับงานบน NezWorks ถือว่าคุณรับทราบและยอมรับข้อตกลงพื้นฐานข้างต้น
